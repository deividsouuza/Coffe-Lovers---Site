# Fotografia própria · Encerramento

Imagem criada com a ferramenta integrada `image_gen`, pela skill imagegen,
em modo de geração, sem CLI/API externa ou imagem de referência como fundo.
Os arquivos consumidos pelo site são locais:

| Arquivo | Dimensões | Peso |
| --- | --- | --- |
| `src/assets/images/farewell/pausa-480.webp` | 480 × 600 | 21.118 bytes |
| `src/assets/images/farewell/pausa-960.webp` | 960 × 1200 | 68.986 bytes |

O original de 1122 × 1402 px permanece em
`C:/Users/laris/.codex/generated_images/01a19bc1-8a36-7742-83a6-1a57751ade1c/exec-a3ba84b5-274a-4c1d-9de5-56211607ebe6.png`.
Esse caminho não é referenciado em runtime; os dois WebPs pertencem ao repositório.
A otimização temporária com Pillow redimensionou e comprimiu o original sem
alterar a composição, com qualidade WebP 80 e 82. Nenhuma dependência foi adicionada
ao projeto. A imagem tem dimensões reservadas, `srcSet`, `sizes`, `loading="lazy"`,
`decoding="async"` e alt descritivo. Não contém texto ou interface incorporada.

A textura `src/assets/textures/paper-grain.svg` é própria, procedural e estática,
usada somente como detalhe decorativo. O vapor adicional fica no SVG original de
`FarewellVisual.tsx`, oculto para leitores de tela. Sua animação respeita movimento
reduzido e termina após 4,5 segundos.
